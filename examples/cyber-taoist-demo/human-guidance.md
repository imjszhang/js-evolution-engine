# Project-local guidance (in-地化条款)

> This file is maintained by the **host operator**, not by the engine and not
> by the upstream cyber-taoist repository. Universal principles live in
> `cyber-taoist/docs/CONSTITUTION.md` and `cyber-taoist/docs/SKILL.md` and are
> injected via `agentContextDocs`. **Do not** copy or modify those documents
> here. Use this file only for clauses that are specific to *this* subject
> (this account, this project, this operator).

## Subject definition (示例)

- The subject of this evolution loop is "this engine + the X account it operates".
- Survival depends on: continuing to produce useful suggestions for the
  operator, and maintaining the operator's trust in the loop.

## Core layer (must not die — 示例)

- Login credentials and 2FA recovery for the X account.
- The single revenue-relevant DM channel with existing customers.
- Legal identity and tax-relevant records.

## Off-limits transactions (示例)

- Anything that risks permanent platform suspension.
- Anything that crosses a hard legal/ethical line.
- Any action that requires more than a single low-traffic publishing slot
  without explicit operator approval.

## Notes for the agent

- When the universal SKILL.md asks "who is the subject?", answer using the
  *Subject definition* above, not from your training prior.
- When SKILL.md asks "what is the core layer?", use the list above. Treat
  any action affecting these as `layer: core` and route through human review.
- Probes must respect the *Off-limits transactions* list regardless of how
  promising the hypothesis looks.
